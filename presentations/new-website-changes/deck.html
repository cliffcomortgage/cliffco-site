The strategic insight: the same trust signals that win Google E-E-A-T are the same signals LLMs use to decide who to cite. SEO and AEO are now one system. We built for both at once.

Where the rebuild had

The audit (captured in seo-aeo-research/01-technical-seo.md) flagged areas where the new SEO + AEO standards needed the site to do more:

The old cliffcomortgage.com
  • WordPress + Elementor / ElementsKit stack — predates the current Core Web Vitals bar; structurally limited on INP (now weighted equally with LCP and CLS).

  • No metro-level landing pages for priority markets — local SEO needs unique city/metro content beyond a branch list to win local-pack rankings.
  • Some leadership references hadn't been refreshed to match the current org structure.

02 · Loan officers
Author authority

Every LO page,
restructured for trust signals.

Each LO already had a page on the old site. The rebuild restructures those pages with the schema, URLs, and external trust anchors Google and LLMs now read to verify expertise.

What the restructured pages add

  • Consistent URL pattern: /loan-officers/[name-nmlsid]/
  • Full Person schema with the LO's NMLS ID
  • sameAs link to NMLS Consumer Access (the federal trust anchor)
  • Schema-tagged specialties, territory, and licensed states
  • Languages-spoken surfaced for bilingual-LO discovery

Why this is the #1 lever

Author authority is the single highest-leverage move for both Google E-E-A-T and LLM citation eligibility.

Google's quality raters and ChatGPT/Claude/Perplexity all weight content by who wrote it. Without machine-readable, NMLS-linked authorship, content is functionally anonymous to those systems. The new pages fix that.

38+ LO pages now run on the restructured template. The rest follow as content reviews complete.
